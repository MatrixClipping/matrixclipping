perguntas

Sobre o print em lote.

O que é print em lote?

É enviar vários links de uma vez e receber o screenshot de cada notícia, sem abrir página por página. Na Matrix Clipping, os prints de um lote são feitos em paralelo.

Como envio os links?

Cole a lista, envie uma planilha ou mande pela API a partir do seu sistema.

O screenshot sai da página inteira?

Sim. Você escolhe página inteira ou área visível, versão desktop ou celular. A matéria também pode ser recortada, com a centimetragem calculada.

E se um portal estiver fora do ar?

O sistema tenta de novo sozinho. Se ainda assim não der certo, o link fica marcado no lote e não trava o resto.

Lotes de clientes diferentes disputam a fila?

Não. Os lotes são processados com revezamento, e cada plano tem a sua capacidade de prints simultâneos. O lote menor não espera o maior.

Em que formato recebo os prints?

Imagem e PDF, prontos para o relatório, e também pela API e pelo integrador (webhook, FTP ou e-mail).
