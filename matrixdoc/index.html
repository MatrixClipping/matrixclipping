perguntas

Sobre o MatrixDoc.

O que é o MatrixDoc?

É a ferramenta que lê PDF e Excel: identifica título, texto e corpo de cada item e entrega no formato que você escolher, como JSON, INSERT para banco de dados, envio por API ou um relatório personalizado.

Quais arquivos posso enviar?

PDF com texto selecionável, Excel (.xlsx) e CSV. Para PDFs digitalizados como imagem, fale com a gente.

Para quais bancos o INSERT é gerado?

MySQL, PostgreSQL e SQL Server. Você define o nome da tabela e qual campo vai em cada coluna.

Posso escolher só alguns campos?

Sim. Você marca os campos que quer (título, subtítulo, corpo, data, veículo, autor) e a saída traz só eles.

Consigo repetir o mesmo processo toda semana?

Sim. Salve o modelo com os campos e o formato de saída, e o próximo arquivo sai no mesmo padrão.

O resultado pode ir direto para o meu sistema?

Sim. Pela MatrixAPI você envia o arquivo e recebe o JSON, com aviso por webhook quando o processamento termina.
