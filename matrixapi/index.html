perguntas

Sobre a MatrixAPI.

O que é a MatrixAPI?

É a API da Matrix Clipping: as mesmas ferramentas do painel (MatrixShot, MatrixMeter e MatrixDoc) chamadas direto do seu sistema, com respostas em JSON.

Como funciona a autenticação?

Você cria um token no painel e envia no cabeçalho Authorization de cada chamada. O token aparece uma única vez e pode ser revogado a qualquer momento.

O que são escopos?

São as permissões do token: ele pode só ler o consumo, só executar o MatrixShot, ou o que você liberar. Um token vazado não abre mais do que deveria.

O consumo pela API é diferente do painel?

Não. Cada chamada conta na mesma franquia mensal, e você acompanha tudo no consumo, separado por origem.

Preciso ficar consultando se o lote terminou?

Não. Com o MatrixLink, o seu sistema recebe um aviso por webhook quando o lote termina.
